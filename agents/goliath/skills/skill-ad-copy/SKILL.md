# skill-ad-copy — Голиаф

Генератор продающих текстов под правила копи Зерокодера. LLM-driven — этот
скилл = инструкция Claude. Помощника на Python нет, агент пишет напрямую в
своей сессии.

## Когда вызывать

- skill-hypothesis предлагает новые креативы → нужно 3-4 текстовых варианта.
- Phase 2: ротация креативов по понедельникам — подменить топ-2 худших на 4 новых.
- Валерий просит «дай тексты для openclaw H08 v3».

## Контракт

**Вход** (передаётся в prompt):
- `product` — sysai / openclaw / n8n / law
- `count` — обычно 4
- `formula` — `kennedy-8p` / `4u` / `pas` / `mixed`
- `basis` — `winners` (по референсам) / `fresh` (новый угол) / `moderation_fix`
- `hypothesis_id` — `H<NN>` или `H00` для one-off
- `audience_anchor` — короткий якорь (см. ниже «Триггеры ЦА»)

**Выход** — список объектов:

```json
[
  {
    "title": "Заголовок до 56 символов",
    "title2": "Доп.заголовок до 30 символов (опционально)",
    "body": "Текст до 81 символа. Чёткая выгода + CTA.",
    "formula_used": "kennedy-8p",
    "anchors_used": ["без кода", "вторая профессия 45+"]
  },
  ...
]
```

## Триггеры ЦА Зерокодера (обязательно использовать)

ЦА — мужчины 40-50, руководители, 81% не кодят. Память
[[ЦА Зерокодера — М 40-50, руководители]]. Ключевые анкеры:

| Анкер | Когда использовать |
|---|---|
| **«без кода»** / «без программирования» | sysai, openclaw, n8n — снять барьер |
| **«вторая профессия 45+»** | sysai, openclaw — карьерная смена |
| **«встрой ИИ в бизнес»** | openclaw, n8n — для текущих руководителей |
| **«ИИ-агент / AI-сотрудник»** | openclaw, n8n — для тех кто слышал хайп |
| **«юристам без перегрузки»** | law (специфично) |
| **«экономь 10+ часов в неделю»** | n8n — автоматизация |

## Запрещённые формулировки

Из памяти [[Стиль копирайтинга]]:
- Без нейрослопа: «революционный», «передовой», «незаменимый»,
  «мощный инструмент»
- Без воды: «откройте новые возможности», «выведите бизнес на новый уровень»
- НЕ называть конкретные бренды (Zerocoder/Skolkovo/Росбанк) per
  [[Без реальных проектов]] — только «из моего опыта», обобщённо

## Формулы

### Kennedy-8P (для длинных body, 80+ chars)

P1 problem → P2 promise → P3 proof → P4 path → P5 price/anchor → P6 push (CTA)
+ опционально P7 punishment (что без этого) + P8 P.S.

### 4U (для коротких заголовков)

Useful · Urgent · Unique · Ultra-specific. Цифры обязательны.

### PAS (Pain · Agitate · Solution)

Для middle-funnel — после 1-2 касаний.

### Mixed

Title по 4U, body по PAS, P8 как закрывающий CTA.

## Инварианты

- **Title ≤ 56 chars, Title2 ≤ 30 chars, Body ≤ 81 char** — лимиты Я.Директа.
- **Цифры в 50%+ заголовков** — «5 кейсов», «за 14 дней», «без 200 часов курсов».
- **CTA в каждом body** — «начни сейчас», «забронируй вебинар», «открой...».
- **UTM не в ad-copy** — это работа skill-utm, передаётся отдельно при создании
  объявления через skill-campaign-control.
- **Один пакет = одна формула** — если запросили `kennedy-8p`, не мешать с PAS
  в одном пакете.
